# Traceability

Every `##` and `###` section of every spec and design document, with the code that implements it and the tests that verify it (docs/plan.md, P15; Definition of Done 3). Sections are named as their headings; a `###` section is written "Parent › Child". `scripts/test/traceability.test.ts` checks that every heading has a row, that every path named here exists, and that no gap below is open.
