How it fits together

Tidewater reads merged pull requests from the repositories you connect. Nothing else in the repository is read.

Each pull request becomes a draft line. The author can edit it, mark it internal, or leave it as it is.

On publish, the drafts for the week are grouped by team and sent to every channel you have connected.

Channels are email digests, Slack threads and a public page. Each can be turned off on its own.

Everything Tidewater sends can be undone for one hour after it goes out.
