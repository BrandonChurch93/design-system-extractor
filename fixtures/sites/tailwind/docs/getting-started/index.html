Getting started

Install the command line tool, connect a repository, and publish.

You need a GitHub account with access to the repository and about five minutes.

The command line tool asks for a token once and keeps it in your system keychain.

Run the two commands below from the root of the repository you want to publish.

The first connects the repository. The second writes a note for everything merged since last Friday.

tidewater init --repo acme/web
tidewater publish --since last-friday

Publishing posts to every connected channel. Try it on a test channel first.
